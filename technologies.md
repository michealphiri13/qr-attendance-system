# 🔧 Technologies Used in QR Attendance System

## Backend
- **PHP 8.2** - Server-side logic, database handling
- **MySQL/MariaDB 10.4** - Database management
- **C++** - Underlying PHP extensions (GD, ZIP) are written in C++

## Frontend
- **HTML5** - Page structure and semantic elements
- **CSS3** - Styling, animations, responsive design
- **JavaScript (ES6)** - QR scanning, dynamic interactions, AJAX

## Libraries & APIs
- **html5-qrcode** - Camera-based QR scanning
- **PHPSpreadsheet** - Excel export functionality
- **chillerlan/php-qrcode** - QR code generation
- **Composer** - PHP dependency management

## Environment
- **XAMPP** - Local development server
- **Apache 2.4** - Web server
- **Git** - Version control
- **GitHub** - Code hosting

## Compiled with C++
The following PHP extensions used in this project are written in C++:
- GD extension (image processing for QR codes)
- ZIP extension (Excel file compression)
- MySQLi extension (database communication)
