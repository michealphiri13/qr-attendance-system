# 📱 QR Attendance System

A complete, enterprise-ready attendance management system that replaces paper sign-in sheets with QR code scanning. Perfect for organizations to track employee attendance, generate payroll reports, and manage events.

## ✨ Features

### 👥 User Management
- **Employee Registration** - Workers can create their own accounts
- **Role-Based Access** - Separate dashboards for Admin and Employees
- **Secure Authentication** - Password hashing and session management

### 📷 QR Code Check-in/out
- **One-Tap Check-in** - Scan QR code to record arrival time
- **Auto Check-out** - Scan again to record departure time
- **Late Detection** - Automatically marks late arrivals after deadline
- **Hours Calculation** - Automatically calculates total hours worked

### 👔 Admin Dashboard
- **Employee Management** - View, manage, and delete employees
- **Attendance Overview** - See who checked in today
- **Real-time Stats** - Total employees, check-ins, hours worked
- **Monthly Payroll** - Generate salary reports based on hours worked

### 📊 Reports & Analytics
- **Payroll Export** - Download CSV reports for salary processing
- **Attendance History** - View complete attendance logs
- **Employee Timesheets** - Individual attendance records

### ⚙️ System Settings
- **Company Configuration** - Customize company details
- **Dark Mode** - Toggle between light and dark themes
- **Password Management** - Secure password updates
